# C Day 104 - Student Attendance Management System

## Description
A menu-driven C application for storing and managing student attendance records.

## Features
- Add student attendance records
- Display all students
- Search students by ID
- Calculate attendance percentage
- Identify attendance below 75%
- Store records permanently in a text file

## Files
- `attendance.c` - Main C program
- `attendance.txt` - Sample attendance records

## Requirements
- GCC compiler

## How to Compile
```bash
gcc attendance.c -o attendance
```

## How to Run
On Windows:
```bash
attendance.exe
```

Keep `attendance.txt` in the same folder as the executable.

## Concepts Used
- Structures
- Functions
- File handling
- Searching records
- Percentage calculations
- Input validation
